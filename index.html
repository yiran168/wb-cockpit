WorkBuddy ⇄ Cockpit Tools
账号格式转换器

アカウント変換✦コンバーター

在 WorkBuddy 导出格式与 Cockpit Tools 账号格式之间自由转换。
纯前端实现，无需服务器，数据不会离开你的浏览器。

立即使用 查看格式
変換開始
converter — workbuddy-cockpit.js
📥

拖拽 JSON 文件到这里

或点击选择文件

转换成功
🛡

隐私优先

所有转换在浏览器本地完成。你的 access_token 和 refresh_token 不会发送到任何服务器。

⚡

自动识别

粘贴 JSON 后自动检测是 WorkBuddy 格式还是 Cockpit Tools 格式，无需手动选择。

📅

智能日期处理

自动处理 expires_at 字段：WorkBuddy 的日期字符串与 Cockpit Tools 的 Unix 时间戳互转。

  "email": "63139186",
  "uid": "abb90fa7-xxxx",
  "expires_at": "2026-11-17 17:45:36",
  "access_token": "eyJ...",
  "refresh_token": "eyJ..."
}
