WorkBuddy ⇄ Cockpit Tools
账号格式转换器

在 WorkBuddy 与 Cockpit Tools 之间自由转换账号格式。纯前端实现，数据始终留在你的浏览器中。

立即使用 查看格式›
変換、始めよう。

转换，轻而易举。

粘贴 JSON，方向自动识别，时间精度到毫秒。

拖入 JSON 文件

或点击选择文件

细节，处处用心。

为账号数据而设计的三重保障。

隐私优先

所有转换在浏览器本地完成。access_token 与 refresh_token 不会发送到任何服务器。

自动识别

粘贴 JSON 后自动检测是 WorkBuddy 还是 Cockpit Tools 格式，无需手动选择方向。

毫秒级精度

expires_at 以毫秒时间戳写入，与 Cockpit Tools 内部表示完全一致；回转时自动还原为本地日期。

格式参考。
